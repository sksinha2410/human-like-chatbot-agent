# Integration Examples

This directory contains examples of integrating the chatbot into various applications.

## Examples

1. **React Integration** - `react-example.jsx`
2. **Vue Integration** - `vue-example.vue`
3. **Node.js Backend** - `nodejs-example.js`
4. **Python Integration** - `python-example.py`

## Usage

These are example code snippets showing how to integrate the chatbot API into different platforms and frameworks.

### React Example

See `react-example.jsx` for a complete React component with hooks.

### Vue Example

See `vue-example.vue` for a Vue 3 composition API component.

### Backend Integration

See `nodejs-example.js` for server-to-server integration.

### Python Integration

See `python-example.py` for Python requests-based integration.

## Configuration

All examples assume the API is running at `http://localhost:3000`. Update the `API_URL` constant in each file to match your deployment URL.
